# Realms of Eldoria

## [Download the launcher](https://github.com/WisCorpX/eldoria-updates/releases/latest/download/EldoriaLauncher.exe)

**[EldoriaLauncher.exe](https://github.com/WisCorpX/eldoria-updates/releases/latest/download/EldoriaLauncher.exe)** - installs the game and keeps it up to date.

1. Download **EldoriaLauncher.exe** and put it in an empty folder (for example `C:\Games\Eldoria`).
2. Open it. If Windows says *"Windows protected your PC"*, click **More info** -> **Run anyway**.
3. Click **INSTALL** (about 2.5 GB the first time).
4. From then on just open the launcher and click **PLAY** - it downloads only what changed in each update.

Patch notes: [latest release](https://github.com/WisCorpX/eldoria-updates/releases/latest)
